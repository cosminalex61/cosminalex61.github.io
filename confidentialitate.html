Politica de confidențialitate

Această politică descrie datele folosite de RegistruCasa când conectezi contul Gmail.

Date folosite

RegistruCasa solicită permisiunea Gmail gmail.compose pentru crearea ciornelor și, acolo unde opțiunea este disponibilă, pentru trimiterea mesajelor la cererea ta. Integrarea folosește documentele selectate și, după caz, destinatarii, subiectul și corpul mesajului. Aplicația nu citește mesajele primite.

Stocare și transmitere

Aplicația transmite conținutul mesajului și atașamentele către Gmail când alegi să creezi o ciornă sau să trimiți un mesaj. Gmail păstrează ciorna sau mesajul trimis în contul tău. Dacă trimiți mesajul, conținutul ajunge la destinatarii aleși.

RegistruCasa stochează tokenurile de autorizare pe calculatorul unde rulează aplicația pentru a reutiliza conexiunea. Versiunea web locală păstrează în baza aplicației adresele recente introduse de utilizator și starea operațiunii de creare a ciornei sau de trimitere.

Retragerea accesului și ștergerea datelor

Poți retrage accesul RegistruCasa din conexiunile contului Google. Poți șterge ciornele și mesajele din Gmail. Pentru ajutor cu datele locale și fișierele de autorizare, folosește adresa de suport asociată aplicației în ecranul de autorizare Google.

Utilizarea limitată a datelor Google

RegistruCasa folosește datele Google pentru funcțiile Gmail descrise aici și respectă politica Google API Services User Data Policy, inclusiv cerințele Limited Use. Aplicația nu vinde datele Google și nu le folosește pentru publicitate.

Vizitarea acestui site

Aceste pagini de informare sunt găzduite pe GitHub Pages. GitHub poate înregistra adresa IP a vizitatorilor în scopuri de securitate, conform politicii sale de confidențialitate.
